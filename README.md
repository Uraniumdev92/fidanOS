# fidanOS / OkulOS 1.0
Akilli tahta icin Linux tabanli canli ISO (BIOS + UEFI).

GitHub tek dosya limiti nedeniyle ISO parcalara bolunmustur.

## Birlestirme (Windows, CMD)
    copy /b OkulOS-1.0.iso.part00+OkulOS-1.0.iso.part01+... OkulOS-1.0.iso
Kolay yol: parcalari bir klasore indirin ve `birlestir.bat` dosyasini calistirin.

Dogrulama (SHA-256 baslangici): 9f4b69bed6dc2179
Sonra Rufus (DD modu) veya balenaEtcher ile USB'ye yazin.
